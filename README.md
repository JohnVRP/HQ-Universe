# HQ Universe

O **HQ Universe** é um site de e-commerce desenvolvido para a venda e organização de histórias em quadrinhos e mangás. O catálogo é dividido entre **Mangás, Marvel e DC Comics**, permitindo visualizar produtos, consultar estoque e adicionar itens ao carrinho.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Bootstrap
- PHP
- MySQL

## Funcionalidades

- Catálogo dividido por categorias
- Pesquisa de produtos
- Página individual de cada produto
- Informações de autor, publicação, páginas e ISBN
- Controle de estoque integrado ao banco de dados
- Carrinho de compras
- Adição e remoção de produtos
- Cálculo de entrega
- Sistema de login e cadastro
- Lista de desejos
- Layout responsivo

## Banco de Dados

O projeto utiliza **MySQL** para armazenar informações de produtos, categorias, estoque, usuários e demais dados necessários ao funcionamento do site.

## Estrutura

O projeto possui páginas específicas para **Mangás, Marvel e DC Comics**, além dos arquivos responsáveis pelo carrinho, produtos, pesquisa, autenticação e conexão com o banco de dados.

## Objetivo

Criar uma plataforma organizada e intuitiva para explorar e comprar HQs e mangás em um único ambiente.
