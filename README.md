# 📚 HQ Universe

O **HQ Universe** é um projeto acadêmico de e-commerce desenvolvido para reunir **HQs e mangás** em uma única plataforma.

O sistema permite explorar títulos de **Mangás, Marvel e DC Comics**, pesquisar produtos, visualizar informações detalhadas, consultar disponibilidade em estoque e utilizar um carrinho de compras.

O projeto foi desenvolvido com foco na aplicação prática de tecnologias de desenvolvimento web, integrando front-end, back-end e banco de dados.

## 🚀 Funcionalidades

- Catálogo de HQs e mangás
- Categorias de Mangás, Marvel e DC Comics
- Pesquisa de produtos
- Páginas individuais para os produtos
- Informações de autor, ano de publicação, páginas e ISBN
- Controle de estoque integrado ao banco de dados
- Carrinho de compras
- Adição e remoção de produtos
- Atualização de quantidade no carrinho
- Lista de desejos
- Sistema de login e cadastro
- Cálculo de entrega por CEP
- Layout responsivo

## 🗄️ Banco de dados

O projeto utiliza **MySQL** para armazenar e gerenciar informações como:

- Produtos
- Categorias
- Estoque
- Usuários
- Pedidos
- Itens do pedido

Os produtos possuem IDs individuais utilizados pelas páginas e pelo carrinho para garantir que cada operação seja realizada sobre o produto correto.

## ⚙️ Como executar localmente

### Requisitos

Para executar o projeto localmente é necessário possuir:

- PHP
- MySQL
- Apache
- XAMPP ou ambiente equivalente

### Instalação

1. Clone este repositório:

```bash
git clone URL-DO-REPOSITORIO
```

2. Coloque o projeto dentro da pasta:

```text
xampp/htdocs/
```

3. Inicie no XAMPP:

```text
Apache
MySQL
```

4. Abra o phpMyAdmin.

5. Crie o banco de dados utilizado pelo projeto.

6. Importe o arquivo `.sql` disponibilizado com o projeto.

7. Confira as configurações de conexão com o banco no arquivo de conexão PHP.

8. Abra o projeto pelo navegador:

```text
http://localhost/NOME-DA-PASTA/
```
